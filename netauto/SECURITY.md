# Security Policy

## Supported versions

NetAuto is currently at `0.1.0-dev`. Security fixes land on the default branch.

## Reporting a vulnerability

Report vulnerabilities through the GitHub private vulnerability reporting form:

https://github.com/sonix-devs/netauto/security/advisories/new

Do not open a public issue for a security vulnerability.

## What to include

- Version and operating system
- Steps to reproduce or a minimal fixture
- Observed impact and any suggested fix

## Response expectations

We aim to acknowledge reports within 5 business days and provide a status update within 14 days.

## Scope

In scope: NetAuto parsers, storage layer, CLI, terminal UI, desktop GUI, and build scripts.

Out of scope: third-party dependencies unless exploitable through NetAuto, and issues requiring physical access to an unlocked machine.

## Disclosure

We coordinate disclosure through the GitHub advisory and credit reporters who want to be named.
