# Roadmap

Projects are built in order, starting with the 17 Sonix-Devs projects (largest to smallest) followed by the 8 personal projects (largest to smallest).

The first project of each language (`logforge-siem` for Rust, `netauto` for Go, `securebaseline` for C++) serves as that language's pilot. Once a pilot is complete, its reusable shell is extracted into `templates/<language>/`.
