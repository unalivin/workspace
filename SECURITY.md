# Security Policy

## Supported versions

Every project in this workspace is at version `0.1.0-dev`. Only the latest commit on the default branch and the latest pre-release of each project receive fixes.

## Reporting channel

Report vulnerabilities privately through the GitHub private vulnerability advisory form of this repository:

https://github.com/NexzaDev/workspace/security/advisories/new

Do not open a public issue for a vulnerability.

## What to include

- The project folder and version or commit
- Operating system and architecture
- Steps to reproduce, with the smallest input that triggers the problem
- The impact you observed and the impact you expect is possible
- Any logs or output, with secrets removed

## Response expectations

This is a volunteer-maintained project without a guaranteed response time. Reports are read, acknowledged in the advisory thread and prioritised by impact. Fixes are released as a new pre-release of the affected project.

## Scope

In scope: the applications, scripts, workflows and templates in this repository.

Out of scope: vulnerabilities in third-party dependencies that are not reachable through these applications (report those upstream), and findings that require an already compromised local user account.

## Disclosure

Please allow a fix to be released before disclosing details. The advisory is published with credit to the reporter unless the reporter asks otherwise.
