# Licenses

## The application

Template App is published by Unalivin under the MIT License, see [../LICENSE](../LICENSE). The copyright line of that file names the holder.

The same name is the publisher in every place a build states one:

| Place | Value |
|---|---|
| About screen, About tab of the terminal UI, `templateapp about` | Publisher |
| `THIRD_PARTY_NOTICES.md` | First paragraph |
| `README.txt` in the Linux and macOS archives | Publisher and copyright line |
| Windows executable | Company name and copyright of the version resource, shown under Properties, Details |
| macOS application | Copyright text of the bundle, shown under Get Info |

The build reads it from `APP_PUBLISHER` in `scripts/lib.sh` and from `Publisher` in `internal/meta/meta.go`; a test fails when the two, or the copyright line of `LICENSE`, disagree.

## Dependencies

[../THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md) lists every Go module that is linked into the application, with its version, its license and the full license text. The file is generated:

```bash
make notices        # regenerate and review
make notices-check  # fail when the committed file is out of date
```

The generator reads the license file of each module from the module cache and identifies the license from its text. It fails when a module has no license file or when the license is not one of:

`MIT`, `BSD-2-Clause`, `BSD-3-Clause`, `Apache-2.0`, `ISC`, `Zlib`, `OFL-1.1`, `CC0-1.0`, `Unlicense`, `MPL-2.0` and the SQLite blessing

The identification compares text; it is not legal advice. Read the notices before you redistribute a changed build.

Email addresses inside upstream license texts are replaced with "(address omitted)", because this repository contains no email address. Nothing else in the texts is changed.

## Where users find them

- In the application: About, Licenses, or `templateapp licenses`.
- In the Linux and macOS downloads: `LICENSE` and `THIRD_PARTY_NOTICES.md`.
- In the Windows download, which is a single executable: About, Licenses, or `templateapp licenses`.

## Icons and fonts

The application icon and the interface icons (navigation, status, severity and action icons) are original drawings generated by code in `internal/brand` and `internal/gui/skin.go`. They are part of the application and under its license. No third-party icon set is used for them.

One font file is part of this repository: `internal/gui/font/NotoSans-Medium.ttf`, the unhinted medium weight of Noto Sans 2.015, used for emphasized text so that the interface has two weights of one family. It is under the SIL Open Font License 1.1. The license file sits next to it as `OFL.txt` and is reproduced in the notices. The font is embedded unchanged and keeps its name.

Two kinds of third-party artwork come with the Fyne toolkit and are part of the binary:

- Fonts: Inter, Noto Sans, DejaVu Sans Mono and EmojiOne Color. Their license texts are reproduced in the Fyne entry of the notices.
- The small glyphs inside toolkit widgets, such as check boxes, drop-down arrows and scroll bars. The Fyne module ships them without a separate license file and does not state where they came from, so they are listed under the license of the Fyne module.
