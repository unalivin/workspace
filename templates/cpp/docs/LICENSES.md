# Licenses

## The application

Template App is published by Unalivin under the MIT License, see [../LICENSE](../LICENSE). The copyright line of that file names the holder.

The same name is the publisher in every place a build states one:

| Place | Value |
|---|---|
| About screen, About tab of the terminal UI, `templateapp about` | Publisher |
| `THIRD_PARTY_NOTICES.md` | First paragraph |
| `README.txt` in the Linux and macOS archives | Publisher and copyright line |
| Windows executable | Company name and copyright of the version resource, shown under Properties, Details. The build reads the copyright line from `LICENSE`. |
| macOS application | Copyright text of the bundle, shown under Get Info |
| CPack package metadata | Vendor |

The scripts read it from `APP_PUBLISHER` in `scripts/lib.sh` and the build from `APP_PUBLISHER` in `CMakeLists.txt`, which the `meta` module receives; tests and the packaging script fail when these, the bundle metadata or the copyright line of `LICENSE` disagree.

## Components

`third_party/components.tsv` is the list of everything that is compiled into the application or its tests. Each row has the name, the version, the license, the source address, the component it arrived inside (for code that a library bundles), where it is used (`app`, `gui` or `tests`), the file with its license text in `third_party/licenses`, the vcpkg port and the upstream commit of that version.

[../THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md) is generated from that list and the license files. Components used only by the tests are left out, because they are not part of a release.

```bash
make notices        # regenerate, then review the difference
make notices-check  # fail when the committed file is out of date
make vuln           # licenses, pinned versions and known vulnerabilities
```

The generator (`tools/gennotices.cpp`) and `make vuln` both stop when a component has a license outside this list:

`MIT`, `Zlib`, `Apache-2.0`, `BSD-2-Clause`, `BSD-3-Clause`, `BSL-1.0`, `ISC`, `OFL-1.1`, `CC0-1.0`, `WTFPL`, `Unlicense`, `Public domain`, `MIT OR Unlicense`

A component that offers a choice is used under one of the listed licenses. The list is reviewed by a person when a row is added: the license is read from the source of the pinned version, and code that a library bundles (for example the stb files inside Dear ImGui) gets a row of its own. The check compares names and texts; it is not legal advice. Read the notices before you redistribute a changed build.

The license files in `third_party/licenses` are copies of the upstream files with one change: an email address is removed, because this repository contains no email address. The unmodified files are in the upstream repositories at the commits named in the list.

## Known vulnerabilities

`make vuln` asks the OSV database (`https://api.osv.dev/v1/query`) for each component that has an upstream commit in the list, and fails when a vulnerability is recorded for that commit. It sends the commit hash and nothing else. A finding that does not apply to the way the application uses the component can be accepted with a line in `third_party/osv-ignore.tsv` that gives the identifier and the reason; the file does not exist while nothing is accepted. `scripts/vuln.sh --offline` runs the other checks without the network.

The same script checks that the versions in the list equal the overrides in `vcpkg.json`, that the vcpkg baseline is the commit that `scripts/dev-setup.sh` installs, and that the vendored SQLite reports the listed version.

## Where users find them

- In the application: About, Licenses, or `templateapp licenses`.
- In the Linux and macOS downloads: `LICENSE` and `THIRD_PARTY_NOTICES.md`.
- In the Windows download, which is a single executable: About, Licenses, or `templateapp licenses`.

## Icons and fonts

The application icon and the interface icons (navigation, status, severity and action icons) are original drawings generated by code in the `brand` module of `src/core` and in `src/gui/icons.cpp`. They are part of the application and under its license. No third-party icon set is used for them.

Two font files are part of this repository: `src/gui/fonts/NotoSans-Regular.ttf` and `NotoSans-Medium.ttf`, the unhinted regular and medium weights of Noto Sans 2.015. The dashboard uses the regular weight for text and the medium weight for headings and emphasized text. Both are under the SIL Open Font License 1.1. The license file sits next to them as `OFL.txt` and is reproduced in the notices. The fonts are embedded unchanged and keep their names.

One third-party font comes with Dear ImGui and is part of the dashboard binary: ProggyForever, which the dashboard uses for fixed-width text. Dear ImGui also contains ProggyClean, which the dashboard does not select. Both are listed in the notices with their license. The marks inside toolkit widgets, such as check marks and drop-down arrows, are drawn by toolkit code and are not image files.

SQLite is compiled into the application from `third_party/sqlite`. SQLite itself is in the public domain.
