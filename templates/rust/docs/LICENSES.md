## Dependencies

[../THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md) lists every Rust crate that the application is built from, on any of the supported operating systems, with its version, its license expression and its source. The license texts follow the table. Crates used only by the tests are left out. The file is generated:

```bash
make notices        # regenerate, then review the difference
make notices-check  # fail when the committed file is out of date
make vuln           # cargo audit, and cargo deny with the license list
```

The generator (`crates/templateapp-app/examples/gennotices.rs`) asks `cargo metadata` for the crates in `Cargo.lock` and reads the license files inside each published crate. Because several hundred crates share a few texts, each distinct text is printed once with the crates that use it. To make that possible the generator changes the texts in these ways and in no other: copyright lines are taken out of the text and listed next to the crate they belong to, runs of empty lines are shortened, spaces at the ends of lines and control characters are dropped, and email addresses are replaced with "(address omitted)", because this repository contains no email address. A file that is not text or is larger than 200,000 bytes is not treated as a license file. The unmodified files ship with each crate.

Some crates are published without a license file. They are listed in their own section with the license their manifest declares.

`cargo deny` (configuration in `deny.toml`) fails when a crate has a license outside this list:

`MIT`, `Apache-2.0`, `Apache-2.0 WITH LLVM-exception`, `BSD-2-Clause`, `BSD-3-Clause`, `ISC`, `Zlib`, `0BSD`, `BSL-1.0`, `CC0-1.0`, `Unicode-3.0`, `OFL-1.1`, `Ubuntu-font-1.0`

A crate that offers a choice, for example `MIT OR Apache-2.0 OR LGPL-2.1-or-later`, is used under one of the listed licenses. The check compares license expressions and texts; it is not legal advice. Read the notices before you redistribute a changed build.

## Where users find them

- In the application: About, Licenses, or `templateapp licenses`.
- In the Linux and macOS downloads: `LICENSE` and `THIRD_PARTY_NOTICES.md`.
- In the Windows download, which is a single executable: About, Licenses, or `templateapp licenses`.

## Icons and fonts

The application icon and the interface icons (navigation, status, severity and action icons) are original drawings generated by code in the `brand` module of `templateapp-core` and in `crates/templateapp-gui/src/icons.rs`. They are part of the application and under its license. No third-party icon set is used for them.

One kind of third-party artwork comes with the egui toolkit and is part of the dashboard binary: the fonts in the crate `epaint_default_fonts` (Ubuntu Light, Hack, Noto Emoji, an emoji icon font and the icon font of egui). Their license files are reproduced in the notices under that crate. The marks inside toolkit widgets, such as check marks and drop-down arrows, are drawn by toolkit code and are not image files.

SQLite is compiled into the application through the crate `libsqlite3-sys`. SQLite itself is in the public domain.
