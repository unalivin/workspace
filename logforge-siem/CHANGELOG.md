# Changelog

## [0.1.0-dev] - 2026-11-21

### Added

- SQLite schema with FTS5 full-text search, deduplication hashes, and audit log hash chain.
- JSON-line and syslog ingestion with UTC normalization and secret redaction.
- Detection rules, alert queue, and saved queries.
- CLI, terminal UI (`ratatui`), and desktop GUI (`eframe`/`egui`).
