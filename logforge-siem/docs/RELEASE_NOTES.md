# Release Notes: LogForge-SIEM v0.1.0-dev (dev beta)

This is an early `0.1.0-dev` dev beta of LogForge-SIEM. Not every planned feature exists yet.

## Downloads

- `logforge-siem-linux-x64.tar.gz`
- `logforge-siem-macos-arm64.tar.gz`
- `logforge-siem-windows-x64.exe`

## Verify checksums

Compare the SHA-256 digest shown on GitHub Releases:

- Linux: `sha256sum logforge-siem-linux-x64.tar.gz`
- macOS: `shasum -a 256 logforge-siem-macos-arm64.tar.gz`
- Windows: `Get-FileHash logforge-siem-windows-x64.exe -Algorithm SHA256`

## Opening unsigned binaries

- **Linux:** `chmod +x logforge-siem`
- **macOS:** Right-click the binary and choose Open.
- **Windows:** Click More info, then Run anyway.
