# Commands and Capability Matrix

| Capability | Dashboard (GUI) | Terminal UI (TUI) | CLI |
|---|---|---|---|
| Overview counts | Overview tab | Overview tab (`1`) | `logforge-app overview` |
| Search events (FTS5) | Search tab | Search tab (`2`) | `logforge-app search <query>` |
| List alerts | Alerts tab | Alerts tab (`3`) | `logforge-app alerts` |
| List sources | Sources tab | Sources tab (`4`) | `logforge-app sources` |
| List detection rules | Rules tab | Rules tab (`5`) | `logforge-app rules` |
| Ingest log file | Sources tab | Sources tab | `logforge-app ingest <source> <file>` |
| Seed demo data | Demo action | Demo action | `logforge-app demo` |
| Theme settings | Settings tab | Settings tab (`7`) | `logforge-app config theme list\|show\|set` |
| Notifier control | Settings tab | Settings tab (`7`) | `logforge-app notifier status\|install\|uninstall\|run` |
